# Task Management App

## Project Description

The Task Management App allows users to add tasks, assign categories, set deadlines, update task statuses, and filter tasks. It also uses local storage to save tasks so they remain available after refreshing the browser.

## Reflection

During this project, one of the main challenges I faced was displaying tasks and making sure the buttons worked correctly. I also had to understand how to store task information using objects and arrays and how to save that information using local storage. I also realized that, I need to study more on DON.

I approached these challenges by breaking the project into smaller steps. First, I created the HTML structure and added the input fields and buttons. Then, I used JavaScript event listeners to add, complete, and remove tasks. I also used functions and conditional statements to filter tasks and check their deadlines. Testing each feature helped me identify and fix problems.
I used most code though in class in combination to searches online for the project.

If I had more time, I would improve the design, add time section, add an option to edit existing tasks, and provide more ways to organize and track task progress.
